# Ecosystem Indicators Workflows

This GitHub organisation contain repositories for research projects associated with the Ecosystem Indicators Workflows initiative.

We aim to provide a modular, fit-for-purpose toolbox that supports the development of ecosystem-specific indicators. Learn more about the project at <https://ecosystem-indicators-workflows.github.io/> and <https://ardc.edu.au/project/ecosystem-indicator-workflows/>.

  - Tools for data preparation [code](https://github.com/Ecosystem-Indicators-Workflows/ARDC-Vocabularies)
  - API test [code](https://github.com/Ecosystem-Indicators-Workflows/test-iucn-get-api)
